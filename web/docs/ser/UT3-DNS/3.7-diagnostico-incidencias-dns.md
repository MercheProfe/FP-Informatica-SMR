# 3.7. Diagnóstico de incidencias DNS

## 1️⃣ Síntomas de un fallo DNS

Un fallo DNS puede impedir acceder a un equipo por su nombre, como `NOMBRE.biblioteca.test`, aunque siga siendo accesible por su dirección IP. También pueden aparecer mensajes que indiquen que no se encuentra el nombre o que la consulta no recibe respuesta.

La **conectividad IP** permite comunicarse con una dirección IP. La **resolución DNS** permite obtener la dirección IP asociada a un nombre. Son comprobaciones diferentes: que funcione la comunicación por IP no garantiza que funcione DNS.

## 2️⃣ Herramientas básicas

Sustituye `IP_DEL_SERVIDOR` por la dirección del servidor del laboratorio y `NOMBRE` por un nombre que ya exista en la zona `biblioteca.test`.

| Herramienta | Sintaxis básica | Utilidad |
| --- | --- | --- |
| `ping` | `ping IP_DEL_SERVIDOR` | Comprobar si se recibe respuesta del servidor por IP. |
| `ipconfig /all` (Windows) | `ipconfig /all` | Consultar la configuración de red y los servidores DNS del cliente. |
| `nslookup` (Windows) | `nslookup NOMBRE.biblioteca.test` | Consultar un nombre mediante el DNS configurado en el cliente. |
| `nslookup` (Windows) | `nslookup NOMBRE.biblioteca.test IP_DEL_SERVIDOR` | Consultar un nombre directamente al servidor DNS indicado. |
| `dig` (Ubuntu) | `dig NOMBRE.biblioteca.test` | Consultar un nombre mediante el DNS habitual. |
| `dig` (Ubuntu) | `dig @IP_DEL_SERVIDOR NOMBRE.biblioteca.test` | Consultar un nombre al servidor DNS indicado. |

## 3️⃣ Procedimiento ordenado

1. **Verificar IP y conectividad.** Comprueba la configuración IP del cliente y la comunicación con la IP del servidor.
2. **Revisar el DNS configurado.** Consulta `ipconfig /all` e identifica qué servidor DNS utiliza el cliente.
3. **Consultar con el DNS habitual.** Ejecuta `nslookup NOMBRE.biblioteca.test` y observa el resultado.
4. **Comparar con una consulta explícita.** Ejecuta `nslookup NOMBRE.biblioteca.test IP_DEL_SERVIDOR` usando el DNS correcto del laboratorio. Compara ambos resultados para localizar el origen del problema.

:::tip[Comprobar antes de cambiar]
Anota la configuración inicial y conserva las evidencias de cada comprobación. Sigue el orden del procedimiento antes de modificar la configuración.
:::

## 4️⃣ Actividad autónoma

En la actividad 3.7 utilizarás el laboratorio existente: `SER-Servidor`, con Windows Server y la zona DNS `biblioteca.test`, y `SER-Cliente`, con Windows, conectados a la red interna.

Provocarás una única incidencia en el DNS configurado en el cliente, recogerás evidencias, seguirás el procedimiento de diagnóstico y restaurarás la configuración inicial. No modificarás el servidor DNS ni sus zonas.
