# Servicios en Red (SER)

En este módulo de **2.º de Sistemas Microinformáticos y Redes (SMR)** aprenderemos a instalar, configurar, administrar y comprobar los servicios que permiten que los equipos de una red se comuniquen y compartan recursos.

Trabajaremos con **máquinas virtuales, Windows Server, herramientas de diagnóstico y Cisco Packet Tracer**, combinando explicaciones breves con prácticas y simulaciones de redes.

## 1️⃣ ¿Qué aprenderemos?

- Configurar redes y comprobar su conectividad.
- Instalar y administrar servicios de red esenciales.
- Configurar clientes para utilizar esos servicios.
- Detectar incidencias y resolver problemas de funcionamiento y seguridad.

## 2️⃣ Unidades de trabajo

| Unidad | Contenido principal |
|---|---|
| **UT0. Repaso y puesta a punto de redes** | Direccionamiento IP, subredes, protocolos, dispositivos, configuración y diagnóstico de redes. |
| **UT1. DHCP** | Asignación automática de direcciones IP, configuración del servidor y gestión de concesiones. |
| **UT2. Servidores web** | Instalación y configuración de servicios HTTP y HTTPS, sitios web y acceso seguro. |
| **UT3. DNS** | Resolución de nombres, dominios, zonas y registros DNS. |
| **UT4. Transferencia de ficheros** | Servicios FTP, usuarios, permisos y transferencia segura de archivos. |
| **UT5. Correo electrónico** | Protocolos y servicios de envío, recepción y gestión del correo. |
| **UT6. Acceso y administración remota** | Administración mediante SSH, escritorio remoto y conexiones seguras. |

## 3️⃣ ¿Cómo trabajaremos?

Combinaremos **laboratorios con máquinas virtuales**, simulaciones en **Packet Tracer** y actividades de diagnóstico. El objetivo será no solo configurar los servicios, sino también **comprender cómo funcionan y demostrar que funcionan correctamente**.
