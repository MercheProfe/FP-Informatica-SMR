# Introducción y objetivos

Hasta ahora hemos trabajado la **resolución de problemas mediante algoritmos**. Hemos aprendido a identificar las entradas, determinar qué proceso debemos realizar y establecer cuál debe ser el resultado.

En esta unidad damos el siguiente paso: **convertir una solución en un programa que pueda ejecutar un ordenador**.

Para ello conoceremos qué es un programa, cómo se representa mediante código fuente y qué herramientas necesitamos para escribirlo, compilarlo y ejecutarlo.

Nuestro lenguaje de programación será **Java** y trabajaremos con **JDK 21**. Como entorno de desarrollo utilizaremos **Visual Studio Code (VS Code)**, que configuraremos para poder crear y ejecutar nuestros programas Java.

:::info[Idea clave]

En esta unidad todavía no nos centraremos en construir programas complejos.

Primero necesitamos comprender **qué ocurre desde que escribimos el código hasta que el ordenador lo ejecuta** y preparar correctamente nuestro entorno de trabajo.

:::

## 1️⃣ ¿Qué vamos a aprender?

A lo largo de esta unidad aprenderemos a:

- comprender la diferencia entre **algoritmo y programa**;
- identificar qué es un **lenguaje de programación**;
- diferenciar entre **código fuente, bytecode y programa en ejecución**;
- comprender de forma básica el proceso de **compilación y ejecución** de un programa Java;
- identificar la función del **JDK**, el compilador `javac` y la **JVM**;
- conocer las herramientas que utilizamos para desarrollar programas;
- preparar nuestro entorno de trabajo con **JDK 21 y Visual Studio Code**;
- crear y ejecutar nuestro **primer programa Java**;
- reconocer las partes fundamentales de la estructura inicial de un programa Java;
- utilizar de forma básica la **terminal integrada de VS Code**;
- comenzar a interpretar los mensajes de error que aparecen al compilar o ejecutar un programa;
- organizar correctamente los archivos y programas que iremos creando durante el curso.

## 2️⃣ Nuestro entorno de trabajo

Durante el curso utilizaremos principalmente:

- **Java 21**, como lenguaje y plataforma de programación.
- **Visual Studio Code**, como entorno para escribir y ejecutar nuestros programas.
- **La terminal**, para comprender y utilizar algunos de los comandos básicos de Java.

Visual Studio Code también puede utilizarse para trabajar con **HTML, CSS y JavaScript**, por lo que podremos emplear el mismo entorno en otros módulos del ciclo.

:::warning[Instalación y configuración]

Las instrucciones completas para instalar y configurar **JDK 21 y Visual Studio Code** están disponibles en **Classroom**.

Seguiremos ese procedimiento para que todos los equipos queden configurados de la misma forma.

:::

## 3️⃣ El recorrido de esta unidad

Partiremos de la solución que ya sabemos expresar mediante un algoritmo y llegaremos hasta la ejecución de nuestro primer programa:

```text
ALGORITMO
    ↓
CÓDIGO JAVA
    ↓
COMPILACIÓN
    ↓
BYTECODE
    ↓
JVM
    ↓
EJECUCIÓN
    ↓
RESULTADO
```

Al finalizar la unidad tendremos preparado el entorno necesario para comenzar a programar y podremos centrarnos, en las siguientes unidades, en aprender las instrucciones y estructuras que nos permitirán construir programas cada vez más completos.

:::tip[Al terminar la UT]

Deberías ser capaz de crear un programa Java sencillo en Visual Studio Code, ejecutarlo y comprender, de forma general, **qué ocurre entre el código que has escrito y el resultado que aparece en pantalla**.

:::
