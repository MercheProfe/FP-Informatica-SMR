# 4.2. Procesamiento y conversiones de datos

En el apartado anterior aprendimos a recoger información del usuario con `Scanner`. Ahora utilizaremos esos valores para **realizar cálculos, convertir datos cuando sea necesario y mostrar resultados comprensibles**.

## 1️⃣ Del dato introducido al resultado

Un programa interactivo sigue el esquema **entrada → proceso → salida**:

1. **Entrada:** solicita y lee los datos.
2. **Proceso:** realiza operaciones con las variables.
3. **Salida:** presenta el resultado al usuario.

Los operadores aritméticos que estudiamos en la UT3 (`+`, `-`, `*`, `/` y `%`) funcionan igual con los valores introducidos por teclado que con los escritos directamente en el código.

Por ejemplo, si el usuario introduce el precio de un artículo y la cantidad comprada, el importe se calcula multiplicando ambos valores.

:::tip[Recuerda]

El tipo de las variables influye en el resultado. En Java, dividir dos valores `int` produce una división entera; si necesitamos decimales, debemos utilizar un tipo adecuado como `double`.

:::

## 2️⃣ Conversión de datos

No siempre recibimos la información en el tipo que necesitamos. Por ejemplo, `nextLine()` devuelve un `String`, aunque el usuario haya escrito `25`.

Para convertir texto a números podemos utilizar:

| Conversión | Instrucción | Ejemplo |
| --- | --- | --- |
| Texto a entero | `Integer.parseInt(texto)` | `"25"` → `25` |
| Texto a decimal | `Double.parseDouble(texto)` | `"19.95"` → `19.95` |

```java
String edadTexto = "18";
int edad = Integer.parseInt(edadTexto);

String precioTexto = "24.50";
double precio = Double.parseDouble(precioTexto);
```

También podemos convertir un entero a decimal cuando una operación lo requiere:

```java
int totalPuntos = 17;
int partidas = 4;
double media = (double) totalPuntos / partidas;
System.out.println(media); // 4.25
```

:::info[¿Por qué utilizar conversiones?]

Leer todos los datos como texto y convertir después los que sean numéricos es una alternativa útil cuando un programa combina nombres, descripciones y cantidades. La conversión solo funciona si el texto tiene un formato numérico válido.

:::

## 3️⃣ Presentación de resultados

La salida debe indicar **qué se ha calculado** y, cuando corresponda, sus unidades.

```java
System.out.println("Importe total: " + total + " €");
```

Para mostrar dos decimales podemos utilizar `printf`:

```java
System.out.printf("Importe total: %.2f €%n", total);
```

`%.2f` representa un número decimal con dos cifras después del separador decimal; `%n` introduce un salto de línea. El separador mostrado puede variar según la configuración regional.

## 4️⃣ Actividad guiada: presupuesto de una reparación

Vamos a crear un programa que solicite el nombre de un equipo, el precio de una pieza y el coste de la mano de obra. Después calculará el subtotal, aplicará un IVA del 21 % y mostrará el presupuesto.

**Código completo — `PresupuestoReparacion.java`:**

```java
import java.util.Scanner;

public class PresupuestoReparacion {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);

        System.out.print("Nombre del equipo: ");
        String equipo = teclado.nextLine();

        System.out.print("Precio de la pieza (€): ");
        double pieza = Double.parseDouble(teclado.nextLine());

        System.out.print("Mano de obra (€): ");
        double manoObra = Double.parseDouble(teclado.nextLine());

        double subtotal = pieza + manoObra;
        double iva = subtotal * 0.21;
        double total = subtotal + iva;

        System.out.println("\nPRESUPUESTO: " + equipo);
        System.out.printf("Subtotal: %.2f €%n", subtotal);
        System.out.printf("IVA (21%%): %.2f €%n", iva);
        System.out.printf("Total: %.2f €%n", total);

        teclado.close();
    }
}
```

**Ejemplo de ejecución** (introduciendo `Portátil`, `80.50` y `30`):

```text
Nombre del equipo: Portátil
Precio de la pieza (€): 80.50
Mano de obra (€): 30

PRESUPUESTO: Portátil
Subtotal: 110,50 €
IVA (21%): 23,21 €
Total: 133,71 €
```

*En un equipo configurado con otra región, los resultados pueden aparecer con punto decimal en lugar de coma.*

**¿Qué hace el programa?** Primero recoge los datos como texto y convierte los importes a `double`. Después calcula subtotal, IVA y total. Por último, presenta los importes con dos decimales.

:::warning[Formato de los números]

En `Double.parseDouble()` el texto decimal debe utilizar un **punto** (`80.50`), no una coma (`80,50`). Si el usuario escribe texto no numérico, el programa producirá un error. Estudiaremos estos casos en el apartado 4.3.

:::

## 5️⃣ Para recordar

- Los datos introducidos por teclado se pueden utilizar en cualquier operación compatible con su tipo.
- `Integer.parseInt()` y `Double.parseDouble()` convierten cadenas numéricas a valores que permiten realizar cálculos.
- Elegir correctamente entre `int` y `double` evita resultados inesperados.
- La salida debe incluir una descripción clara y, si procede, las unidades.
