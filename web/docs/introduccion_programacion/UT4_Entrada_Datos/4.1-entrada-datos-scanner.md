# 4.1. Entrada de datos con Scanner

## 1️⃣ ¿Qué es un programa interactivo?

En la UT3 escribíamos los valores directamente en el código. Un **programa interactivo** permite que el usuario introduzca datos mientras se ejecuta, sin modificar el programa cada vez.

El funcionamiento sigue el esquema que ya conocemos:

**Entrada → Proceso → Salida**

Por ejemplo, un programa puede pedir el precio de un producto (**entrada**), calcular el importe de varias unidades (**proceso**) y mostrar el total (**salida**).

## 2️⃣ La clase `Scanner`

Java dispone de la clase `Scanner` para leer datos introducidos por teclado. Para utilizarla necesitamos importarla y crear un objeto asociado a la entrada estándar, `System.in`:

```java
import java.util.Scanner;

public class EjemploScanner {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);

        System.out.print("¿Cómo te llamas? ");
        String nombre = teclado.nextLine();

        System.out.println("Hola, " + nombre);

        teclado.close();
    }
}
```

- `import java.util.Scanner;` permite utilizar la clase.
- `new Scanner(System.in)` prepara la lectura desde el teclado.
- `System.out.print()` muestra un mensaje sin cambiar de línea.
- `teclado.nextLine()` espera a que el usuario escriba una línea y pulse **Intro**.
- `teclado.close()` cierra el lector al terminar el programa.

:::info[Importante]

El nombre `teclado` lo elegimos nosotros: es la variable con la que utilizamos el lector. Puedes encontrar ejemplos que emplean otros nombres, como `scanner` o `entrada`.

:::

## 3️⃣ Leer distintos tipos de datos

El método de lectura depende del tipo de información que queremos recibir:

| Método | Qué lee | Tipo habitual |
| --- | --- | --- |
| `nextInt()` | Un número entero | `int` |
| `nextDouble()` | Un número decimal | `double` |
| `next()` | Una palabra (hasta el siguiente espacio) | `String` |
| `nextLine()` | Una línea completa, incluidos los espacios | `String` |

Ejemplos de instrucciones:

```java
int edad = teclado.nextInt();
double precio = teclado.nextDouble();
String usuario = teclado.next();
String nombreCompleto = teclado.nextLine();
```

Estas instrucciones suponen que ya hemos creado `teclado` y que la entrada tiene el formato esperado.

:::warning[Atención a los datos introducidos]

Si el programa espera un entero y escribimos texto, se producirá un error durante la ejecución. Además, al combinar `nextInt()` o `nextDouble()` con `nextLine()` puede quedar pendiente el salto de línea. Estudiaremos estos problemas en el apartado **4.3**.

:::

## 4️⃣ Actividad guiada: calcular el coste de unas entradas

Vamos a crear un programa que solicite el nombre de un concierto, el precio de una entrada y el número de entradas. Después calculará el importe total.

**Archivo:** `EntradasConcierto.java`

```java
import java.util.Scanner;

public class EntradasConcierto {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);

        System.out.print("Nombre del concierto: ");
        String concierto = teclado.nextLine();

        System.out.print("Precio de una entrada: ");
        double precio = teclado.nextDouble();

        System.out.print("Número de entradas: ");
        int cantidad = teclado.nextInt();

        double total = precio * cantidad;

        System.out.println("Concierto: " + concierto);
        System.out.println("Importe total: " + total + " €");

        teclado.close();
    }
}
```

**Ejemplo de ejecución** (introduciendo `25.5` como precio):

```text
Nombre del concierto: Festival de verano
Precio de una entrada: 25.5
Número de entradas: 3
Concierto: Festival de verano
Importe total: 76.5 €
```

Observa cómo el programa utiliza tres tipos de datos (`String`, `double` e `int`) y reutiliza los operadores que aprendimos en la UT3.

:::tip[Comprobación]

Ejecuta el programa otra vez con valores distintos y comprueba si el total cambia correctamente. En algunos equipos, el separador decimal aceptado por `Scanner` depende de la configuración regional: puede ser punto o coma.

:::

## 5️⃣ Lo esencial

Un programa interactivo obtiene datos durante su ejecución. Con `Scanner` podemos leer texto y números, guardarlos en variables y utilizarlos en cálculos. Para elegir el método adecuado debemos conocer el tipo de dato que esperamos recibir.

En **4.2 — Procesamiento y conversiones** veremos cómo aprovechar esas entradas en cálculos más completos y cómo transformar texto en valores numéricos.
