# 4.2. La clase `Scanner`

En el apartado anterior vimos que un **programa interactivo** puede pedir información al usuario durante su ejecución. En Java, una de las formas más sencillas de hacerlo es mediante la clase `Scanner`.

En este apartado aprenderemos a preparar `Scanner`, pedir un dato por teclado y guardarlo en una variable. En el siguiente apartado estudiaremos con más detalle cómo leer distintos tipos de datos.

## 1️⃣ ¿Qué es `Scanner`?

`Scanner` es una clase de Java que permite **leer datos** de distintas fuentes. Nosotros la utilizaremos para recoger lo que el usuario escribe con el teclado.

Para usarla necesitamos tres pasos:

1. Importar la clase `Scanner`.
2. Crear un objeto `Scanner` asociado al teclado.
3. Utilizarlo para leer la información introducida.

:::info[Una clase que ya existe]

No tenemos que programar `Scanner` desde cero: Java ya proporciona esta clase en su biblioteca estándar. Por ahora aprenderemos a utilizarla; más adelante estudiaremos las clases y los objetos con mayor profundidad.

:::

## 2️⃣ Importar la clase `Scanner`

Al principio del archivo Java, **antes de declarar nuestra clase**, escribimos:

```java
import java.util.Scanner;
```

La instrucción `import` indica que queremos utilizar la clase `Scanner`, que pertenece al paquete `java.util`.

:::warning[Error frecuente]

La instrucción de importación se escribe fuera de `main` y antes de `public class`. Recuerda el punto y coma final.

:::

## 3️⃣ Preparar la lectura por teclado

Dentro de `main` creamos un objeto `Scanner`:

```java
Scanner teclado = new Scanner(System.in);
```

Veamos las partes de la instrucción:

| Fragmento | Significado |
| --- | --- |
| `Scanner` | Clase que utilizaremos para leer datos. |
| `teclado` | Nombre que damos al objeto para utilizarlo después. |
| `new Scanner(...)` | Crea el objeto `Scanner`. |
| `System.in` | Indica que los datos se leerán de la entrada estándar, normalmente el teclado. |

El nombre `teclado` es una elección nuestra; podríamos utilizar otro nombre descriptivo, pero debemos mantenerlo igual en las instrucciones posteriores.

## 4️⃣ Leer nuestro primer dato

Vamos a pedir el nombre del usuario. Utilizaremos `nextLine()`, que lee una línea de texto hasta que pulsamos **Intro**.

```java
import java.util.Scanner;

public class SaludoInteractivo {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);

        System.out.print("¿Cómo te llamas? ");
        String nombre = teclado.nextLine();

        System.out.println("Hola, " + nombre + ". ¡Bienvenido!");

        teclado.close();
    }
}
```

Una posible ejecución sería:

```text
¿Cómo te llamas? Lucía
Hola, Lucía. ¡Bienvenido!
```

### 🟩 ¿Qué sucede durante la ejecución?

1. El programa muestra la pregunta mediante `System.out.print()`.
2. `teclado.nextLine()` espera a que el usuario escriba y pulse **Intro**.
3. El texto introducido se guarda en la variable `nombre`.
4. `System.out.println()` muestra el saludo utilizando ese valor.

:::tip[`print` y `println`]

`System.out.print()` escribe sin añadir un salto de línea al final. Por eso permite que el usuario escriba su respuesta a continuación de la pregunta.

`System.out.println()` sí añade un salto de línea después de mostrar el mensaje.

:::

## 5️⃣ Leer un número entero

Además de texto, podemos leer números. Para obtener un entero utilizamos `nextInt()` y guardamos el resultado en una variable `int`.

```java
import java.util.Scanner;

public class EdadUsuario {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);

        System.out.print("Introduce tu edad: ");
        int edad = teclado.nextInt();

        System.out.println("Tienes " + edad + " años.");

        teclado.close();
    }
}
```

Una posible ejecución:

```text
Introduce tu edad: 18
Tienes 18 años.
```

En este ejemplo, `nextInt()` espera un número entero. Si escribimos texto en lugar de un número, el programa puede producir un error. Estudiaremos estos problemas en el apartado **4.6**.

## 6️⃣ Cerrar `Scanner` y mantener el código ordenado

En los ejemplos anteriores hemos escrito:

```java
teclado.close();
```

Este método cierra el objeto `Scanner` cuando ya no lo necesitamos. En nuestros programas sencillos lo colocaremos **al final de `main`, después de todas las lecturas**.

:::warning[No cierres el teclado antes de tiempo]

Cuando `Scanner` utiliza `System.in`, cerrarlo también cierra esa entrada. Por eso no debemos intentar seguir leyendo desde el teclado después de llamar a `teclado.close()`.

:::

Como norma inicial, utilizaremos **un solo `Scanner` para leer del teclado** en cada programa y le daremos un nombre descriptivo.

## 7️⃣ Resumen de lo aprendido

| Instrucción | ¿Para qué sirve? |
| --- | --- |
| `import java.util.Scanner;` | Permite utilizar la clase `Scanner`. |
| `Scanner teclado = new Scanner(System.in);` | Prepara la lectura desde el teclado. |
| `teclado.nextLine()` | Lee una línea de texto. |
| `teclado.nextInt()` | Lee un número entero. |
| `teclado.close()` | Cierra el objeto `Scanner` cuando terminamos. |

**Recuerda:** primero mostramos qué dato necesitamos, después lo leemos y finalmente lo utilizamos en nuestro programa.
