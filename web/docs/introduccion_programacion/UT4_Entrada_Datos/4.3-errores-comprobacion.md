# 4.3. Errores frecuentes y comprobación de datos

Cuando un programa pide información por teclado, no siempre recibe los datos que esperamos. Además, algunas instrucciones de `Scanner` pueden producir resultados sorprendentes si se combinan sin cuidado.

En este apartado aprenderemos a **reconocer errores habituales**, interpretar sus causas y comprobar que un programa funciona con diferentes entradas. Todavía no programaremos validaciones con `if` ni repetiremos peticiones con bucles: eso lo veremos en las siguientes unidades.

## 1️⃣ Errores habituales con Scanner

### 🟩 Introducir un dato del tipo incorrecto

Si usamos `nextInt()` y escribimos una palabra en lugar de un número entero, Java lanza una excepción `InputMismatchException` y el programa se interrumpe si no se trata ese error.

```java
Scanner teclado = new Scanner(System.in);
System.out.print("Edad: ");
int edad = teclado.nextInt();
```

La entrada `18` es válida; `dieciocho` no lo es para `nextInt()`.

### 🟧 El salto de línea pendiente

`nextInt()` y `nextDouble()` leen el número, pero **no consumen el salto de línea** que se produce al pulsar Intro. Si después utilizamos `nextLine()`, puede leer ese salto pendiente y devolver una cadena vacía.

```java
System.out.print("Edad: ");
int edad = teclado.nextInt();

teclado.nextLine(); // Consume el salto de línea pendiente

System.out.print("Nombre completo: ");
String nombre = teclado.nextLine();
```

:::tip[Recuerda]

Si después de leer un número con `nextInt()` o `nextDouble()` vas a leer una línea completa con `nextLine()`, revisa si necesitas consumir antes el salto de línea pendiente.

:::

### 🟥 Formato de los decimales

`nextDouble()` interpreta los decimales según la configuración regional del `Scanner`. Dependiendo de ella, puede esperar coma o punto decimal.

Para evitar confusiones en clase, comprobaremos qué formato acepta nuestro programa antes de realizar los cálculos.

## 2️⃣ Errores al convertir datos

Cuando leemos un dato como texto y después lo convertimos, debemos introducir una cadena con el formato adecuado.

```java
String texto = "25";
int cantidad = Integer.parseInt(texto);
```

La cadena `"25"` se puede convertir a entero, pero `"veinticinco"` produce una `NumberFormatException`. Del mismo modo, `Double.parseDouble()` espera un número decimal válido escrito con **punto** como separador decimal, por ejemplo `"12.50"`.

:::warning[No confundas detectar con gestionar]

Por ahora aprenderemos a identificar estos errores y a introducir datos correctos. Más adelante utilizaremos estructuras de decisión y repetición para comprobar entradas y volver a solicitarlas cuando sea necesario.

:::

## 3️⃣ Comprobar que un programa funciona

Que un programa se ejecute sin mostrar errores no significa que sus cálculos sean correctos. Conviene probarlo con **varios conjuntos de datos** y comparar el resultado obtenido con el esperado.

Por ejemplo, si un programa calcula el coste total de una compra, podemos comprobarlo con estas entradas:

| Precio unitario (€) | Unidades | Total esperado (€) |
| --- | --- | --- |
| 10 | 2 | 20 |
| 7.5 | 4 | 30 |
| 0 | 3 | 0 |

Al revisar un programa, comprueba que:

- Solicita los datos necesarios en el orden correcto.
- Guarda cada dato en una variable adecuada.
- Realiza las operaciones previstas.
- Muestra un resultado comprensible.
- Produce los resultados esperados con diferentes entradas válidas.

## 4️⃣ Actividad guiada: corregir una ficha de cliente

Queremos que un programa solicite la edad y el nombre completo de un cliente y después muestre ambos datos. El siguiente código presenta un problema: al introducir la edad, parece que el programa no deja escribir el nombre.

**Versión con el problema:**

```java
import java.util.Scanner;

public class FichaCliente {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);

        System.out.print("Edad: ");
        int edad = teclado.nextInt();

        System.out.print("Nombre completo: ");
        String nombre = teclado.nextLine();

        System.out.println("Cliente: " + nombre + " (" + edad + " años)");
        teclado.close();
    }
}
```

**¿Qué ocurre?** `nextLine()` encuentra el salto de línea que quedó pendiente después de introducir la edad. Por eso no espera un nuevo nombre.

**Versión corregida:**

```java
import java.util.Scanner;

public class FichaCliente {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);

        System.out.print("Edad: ");
        int edad = teclado.nextInt();
        teclado.nextLine();

        System.out.print("Nombre completo: ");
        String nombre = teclado.nextLine();

        System.out.println("Cliente: " + nombre + " (" + edad + " años)");
        teclado.close();
    }
}
```

**Ejemplo de ejecución:**

```text
Edad: 19
Nombre completo: Ana García
Cliente: Ana García (19 años)
```

Prueba el programa con otros nombres y edades para comprobar que ambos datos se leen correctamente.
