# UT4. Entrada de datos y programas interactivos

En la UT3 aprendimos a utilizar **variables, tipos de datos y operadores** para realizar cálculos en Java. Hasta ahora, los valores que necesitaban nuestros programas estaban escritos en el propio código.

En esta unidad aprenderemos a **pedir datos al usuario mientras se ejecuta el programa**. Así podremos utilizar el mismo programa con información diferente, sin modificar su código fuente.

Para ello trabajaremos con la clase `Scanner` y aplicaremos lo aprendido sobre variables y operaciones a situaciones prácticas, como calcular el coste de un viaje o preparar el presupuesto de una reparación informática.

## 1️⃣ ¿Qué aprenderemos?

Al finalizar la unidad seremos capaces de:

- Distinguir entre programas con datos fijos y programas interactivos.
- Solicitar y leer datos por teclado mediante `Scanner`.
- Trabajar con números enteros, decimales y cadenas de texto introducidos por el usuario.
- Procesar los datos y presentar resultados comprensibles.
- Realizar conversiones sencillas entre texto y valores numéricos.
- Reconocer errores frecuentes de entrada y comprobar el funcionamiento de un programa con diferentes datos.

## 3️⃣ ¿Cómo trabajaremos?

Utilizaremos **Java 21 y Visual Studio Code**. En cada apartado teórico veremos los conceptos fundamentales y resolveremos **una actividad guiada** en clase.

Después realizaremos actividades individuales, con enunciados completos pero **sin pistas ni código inicial**. Tendremos que analizar qué datos necesitamos, cómo procesarlos y qué resultados mostrar.
