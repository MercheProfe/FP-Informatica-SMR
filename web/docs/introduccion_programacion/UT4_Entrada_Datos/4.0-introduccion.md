# UT4. Entrada de datos y programas interactivos

Hasta ahora hemos aprendido a crear programas en Java utilizando **variables, tipos de datos y operadores**. Sin embargo, los valores que utilizábamos estaban escritos directamente en el código.

En esta unidad vamos a dar un paso más: **aprenderemos a crear programas que interactúan con el usuario**, solicitando información por teclado, realizando operaciones con los datos introducidos y mostrando los resultados en pantalla.

Para ello utilizaremos la clase `Scanner` de Java, que nos permitirá leer números y textos introducidos durante la ejecución del programa.

## 1️⃣ ¿Qué aprenderemos?

Al finalizar esta unidad seremos capaces de:

- Comprender qué es un programa interactivo y cómo funciona.
- Utilizar la clase `Scanner` para introducir datos por teclado.
- Leer números enteros, decimales y cadenas de texto.
- Almacenar los datos introducidos en variables.
- Realizar operaciones y cálculos con los datos recibidos.
- Convertir cadenas de texto a valores numéricos.
- Identificar y corregir errores habituales en la lectura de datos.
- Desarrollar pequeños programas completos siguiendo el esquema **entrada → proceso → salida**.

## 2️⃣ De la UT3 a la UT4

En la unidad anterior aprendimos a trabajar con variables y operadores.

Por ejemplo, podíamos calcular el precio de una reparación de un ordenador:

```java
double precioPieza = 75.50;
double manoObra = 30.00;

double total = precioPieza + manoObra;

System.out.println("Total reparación: " + total + " €");
```

Este programa funciona correctamente, pero tiene una limitación: **si queremos calcular otra reparación, debemos modificar el código y volver a ejecutarlo**.

En esta unidad aprenderemos a solicitar esos precios al usuario:

```java
import java.util.Scanner;

public class Presupuesto {
    public static void main(String[] args) {

        Scanner teclado = new Scanner(System.in);

        System.out.print("Precio de la pieza: ");
        double precioPieza = teclado.nextDouble();

        System.out.print("Precio de la mano de obra: ");
        double manoObra = teclado.nextDouble();

        double total = precioPieza + manoObra;

        System.out.println("Total reparación: " + total + " €");

        teclado.close();
    }
}
```

Ahora el programa puede calcular diferentes presupuestos sin necesidad de modificar su código.

:::tip[¿Qué ha cambiado?]
Las operaciones son las mismas que en la UT3. La diferencia es que ahora los valores los introduce el usuario durante la ejecución del programa.
:::

## 4️⃣ ¿Cómo vamos a trabajar?

Durante esta unidad utilizaremos **Java 21 y Visual Studio Code**, las mismas herramientas que hemos empleado anteriormente.

Seguiremos una metodología práctica:

1. Comprenderemos un problema sencillo.
2. Identificaremos los datos que necesita el programa.
3. Aprenderemos las instrucciones necesarias para resolverlo.
4. Analizaremos ejemplos de código.
5. Desarrollaremos nuestros propios programas.
6. Comprobaremos su funcionamiento utilizando diferentes datos.

Las actividades comenzarán con ejercicios guiados y aumentarán progresivamente su dificultad.

Trabajaremos con situaciones cercanas, como calcular el coste de un viaje, comprar entradas para un concierto, gestionar cuotas de gimnasio o elaborar presupuestos de reparación de ordenadores.

## 5️⃣ ¿Qué seremos capaces de hacer al finalizar?

Al terminar la UT4 podremos desarrollar un programa que:

- Pregunte al usuario los datos que necesita.
- Guarde esos datos en variables del tipo adecuado.
- Realice cálculos utilizando operadores.
- Muestre resultados claros y comprensibles.
- Funcione con distintos valores sin modificar el código fuente.
