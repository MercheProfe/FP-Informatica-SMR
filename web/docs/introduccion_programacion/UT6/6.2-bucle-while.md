# 6.2. El bucle while

## 1️⃣ Repetir mientras se cumpla una condición

En un taller se registran revisiones de equipos hasta que el técnico indica que ha terminado. No conocemos de antemano cuántos registros habrá. Necesitamos comprobar si queda trabajo antes de cada nueva revisión.

`while` significa «mientras». Evalúa una condición y ejecuta su cuerpo solo si es verdadera. Después vuelve a comprobarla. Puede ejecutar el cuerpo **cero veces** si la condición ya es falsa al principio.

## 2️⃣ Sintaxis y orden de ejecución

Este esquema muestra la estructura, no un programa completo:

```text
estado inicial
while (condición) {
    instrucciones que se repiten
    actualización del estado
}
instrucciones posteriores
```

1. Se prepara el estado inicial antes de entrar.
2. Se evalúa la condición entre paréntesis.
3. Si es verdadera, se ejecuta el cuerpo entre llaves.
4. Se vuelve a la condición tras ejecutar todo el cuerpo.
5. Si es falsa, se continúa después de la llave de cierre.

La actualización forma parte del cuerpo cuando el problema lo requiere. Puede ser un incremento, una resta o una nueva lectura con `Scanner`.

:::warning[No añadas un punto y coma después de while]

En un `while` con cuerpo entre llaves, escribir `while (condicion);` crea un cuerpo vacío. El bloque siguiente deja de ser el cuerpo del bucle y el programa puede quedarse repitiendo sin actualizar nada.

:::

## 3️⃣ Actividad guiada resuelta: cuenta atrás de reinicio

**Problema.** Pedir los segundos de espera de un reinicio simulado. Mostrar los segundos desde ese valor hasta 1 y, después, «Reinicio simulado». Si se introduce 0 o un número negativo, no se muestra la cuenta atrás y se indica que no hay espera. El programa solo muestra mensajes: no reinicia el equipo.

Guarda el programa como `CuentaAtras.java`.

```java
import java.util.Scanner;

public class CuentaAtras {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);

        System.out.print("Segundos de espera: ");
        int segundos = teclado.nextInt();

        if (segundos <= 0) {
            System.out.println("Sin espera previa");
        }

        while (segundos > 0) {
            System.out.println("Quedan " + segundos + " segundos");
            segundos--;
        }

        System.out.println("Reinicio simulado");
        teclado.close();
    }
}
```

### 🟩 Explicación

La lectura inicial fija el estado del bucle. El `if` resuelve el caso sin espera. El `while` solo entra cuando `segundos` es positivo. En cada vuelta muestra su valor y lo reduce una unidad con `segundos--`.

No hay una pausa real entre mensajes: los números se muestran seguidos. El propósito es comprender el recorrido, sin incorporar herramientas de temporización.

### 🟦 Traza con una entrada de 3

Una **traza** registra cómo cambian las variables y qué instrucciones se ejecutan.

| Comprobación | Segundos antes | ¿segundos > 0? | Salida del cuerpo | Segundos después |
| --- | --- | --- | --- | --- |
| 1 | 3 | Verdadero | Quedan 3 segundos | 2 |
| 2 | 2 | Verdadero | Quedan 2 segundos | 1 |
| 3 | 1 | Verdadero | Quedan 1 segundos | 0 |
| 4 | 0 | Falso | No se ejecuta | 0 |

Después se muestra «Reinicio simulado». Con una entrada de 0 se omite el cuerpo por completo. Con una entrada de 1 se ejecuta una sola vuelta.

## 4️⃣ Actualizar en la dirección correcta

La condición expresa cuándo continuar; la actualización debe hacer avanzar el proceso. En la cuenta atrás, incrementar los segundos alejaría el valor del final esperado.

En una lectura repetida, una primera entrada permite evaluar la condición. Si el dato no indica el final, se procesa y se pide el siguiente **dentro del cuerpo**. Si olvidamos esa nueva lectura, volveremos a comprobar siempre el mismo dato.

Un dato reservado para terminar se llama **centinela**. Por ejemplo, 0 puede indicar el final de una serie de cantidades positivas. Ese 0 controla la repetición y no representa una cantidad que debamos procesar.

:::tip[Comprobar los límites]

Comprueba siempre un caso sin iteraciones, otro con una sola y otro con varias. Distingue `>` de `>=`: cambiar el límite puede añadir o quitar una vuelta.

:::
