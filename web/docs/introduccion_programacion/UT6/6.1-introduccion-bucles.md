# 6.1. Introducción a los bucles

## 1️⃣ Un problema que se repite

Un técnico debe mostrar el aviso «Revisar conexiones» para tres puestos de trabajo. Podría escribir tres instrucciones de salida, pero si mañana hay veinte puestos tendría que modificar el programa. Un **bucle** permite escribir una vez la acción y controlar sus repeticiones.

Repetir no significa necesariamente hacer siempre lo mismo con los mismos datos: en cada vuelta podemos mostrar otro número de puesto, leer una temperatura distinta o atender una nueva opción de menú.

## 2️⃣ Las partes de una repetición

| Concepto | Significado |
| --- | --- |
| Cuerpo | Instrucciones que se repiten |
| Iteración | Una ejecución del cuerpo; también se llama vuelta |
| Condición | Expresión booleana que permite continuar o detener la repetición |
| Estado inicial | Valores que tienen las variables antes de empezar |
| Actualización | Cambio que permite avanzar hacia el final del proceso |

En los bucles de Java que estudiaremos, la condición verdadera permite continuar; la condición falsa termina la repetición. `while` y `for` la comprueban antes del cuerpo; `do-while`, después.

Una condición utiliza las comparaciones y operadores lógicos de la UT5. Por ejemplo, `puesto <= 3` pregunta si el número de puesto todavía está dentro del recorrido.

### 🟦 Decidir y repetir

Un `if` decide una vez si ejecuta su bloque. Un bucle vuelve a comprobar su condición según sus reglas y puede ejecutar su cuerpo varias veces. Podemos incluir decisiones dentro de la repetición: por ejemplo, avisar solo cuando una temperatura supera un límite.

## 3️⃣ Actividad guiada resuelta: avisos para tres puestos

**Problema.** Mostrar un aviso para los puestos 1, 2 y 3, y anunciar después que la ronda ha terminado. Usaremos `while` para observar la repetición; en el siguiente apartado estudiaremos su sintaxis con detalle.

Guarda el programa como `AvisosPuestos.java`.

```java
public class AvisosPuestos {
    public static void main(String[] args) {
        int puesto = 1;

        while (puesto <= 3) {
            System.out.println("Puesto " + puesto + ": revisar conexiones");
            puesto++;
        }

        System.out.println("Ronda terminada");
    }
}
```

### 🟩 Explicación y resultado

La variable `puesto` empieza en 1. Mientras su valor sea menor o igual que 3, se muestra el aviso y se incrementa con `puesto++`, que suma una unidad. Al llegar a 4, la condición es falsa y se continúa después del bucle.

```text
Puesto 1: revisar conexiones
Puesto 2: revisar conexiones
Puesto 3: revisar conexiones
Ronda terminada
```

| Comprobación | Valor de puesto | ¿`puesto <= 3`? | Qué ocurre |
| --- | --- | --- | --- |
| Primera | 1 | Verdadero | Aviso del puesto 1; pasa a 2 |
| Segunda | 2 | Verdadero | Aviso del puesto 2; pasa a 3 |
| Tercera | 3 | Verdadero | Aviso del puesto 3; pasa a 4 |
| Cuarta | 4 | Falso | Termina el bucle |

Hay tres iteraciones, pero cuatro comprobaciones de la condición. La última comprobación no ejecuta el cuerpo.

## 4️⃣ Cómo puede no terminar un bucle

Un **bucle infinito** continúa sin alcanzar una salida. En el programa anterior, si eliminamos la actualización, `puesto` seguirá valiendo 1 y la condición seguirá siendo verdadera. Una actualización en dirección incorrecta también puede impedir el final.

:::warning[La condición no cambia por sí sola]

Antes de ejecutar un bucle, identifica qué dato cambia y por qué ese cambio permitirá terminar. En programas interactivos, el cambio puede ser una nueva entrada del usuario. Un bucle no tiene que incrementar siempre una variable, pero sí necesita una forma de alcanzar su final.

:::

Si un programa repite mensajes sin detenerse, interrúmpelo con el botón de parada de VS Code o con `Ctrl+C` si está ejecutándose en la terminal. Después revisa el estado inicial, la condición y la actualización.
