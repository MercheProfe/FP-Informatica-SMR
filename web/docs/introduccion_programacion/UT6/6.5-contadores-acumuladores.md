# 6.5. Contadores y acumuladores

## 1️⃣ Conservar resultados entre vueltas

Un taller registra el tiempo de revisión de varios equipos. No basta con leer cada tiempo: al terminar quiere saber cuántas revisiones ha registrado, cuántas han sido largas, el tiempo total, la media y los tiempos extremos.

Podemos obtener esos resultados conforme llegan los datos, sin guardar una lista. Solo conservamos las variables necesarias para el resumen.

## 2️⃣ Contar y acumular

| Variable | Qué representa | Actualización habitual |
| --- | --- | --- |
| Contador | Cuántas veces ocurre algo | Sumar una unidad por caso |
| Acumulador | Suma de cantidades que pueden ser distintas | Sumar el valor de cada dato |

Un contador de revisiones comienza en 0 y aumenta uno por revisión. Un acumulador de minutos comienza en 0 y recibe el tiempo de cada revisión. La expresión `total += minutos` equivale a `total = total + minutos`.

Se inicializan **antes del bucle**: así conservan los resultados de las vueltas anteriores. Si se reinician en cada vuelta, al final solo reflejarán el último dato.

Un contador puede actualizarse en todas las vueltas o solo cuando se cumpla un `if`. No confundas el número de datos leídos con el número de datos que cumplen una condición.

## 3️⃣ Media, máximo y mínimo

### 🟦 Media

La media es la suma dividida entre la cantidad de datos incluidos. Si solo sumamos algunos datos, debemos contar esos mismos datos para calcularla. La división requiere una cantidad mayor que cero.

Si ambos operandos son enteros, Java realiza una división entera y elimina la parte decimal. Para una media decimal, al menos uno de los operandos debe ser decimal. En la actividad, el total es `double`.

### 🟩 Máximo y mínimo

El máximo es el mayor dato leído; el mínimo, el menor. Una estrategia segura es tomar **el primer dato válido como ambos extremos**. Con los siguientes, se compara y se sustituye el extremo correspondiente si procede.

No conviene suponer que el mínimo empieza en 0: si todas las duraciones son positivas, ese 0 no pertenece a los datos y produciría un resultado incorrecto. Tampoco debemos inventar un límite enorme como valor inicial.

## 4️⃣ Actividad guiada resuelta: tiempos de revisión

**Problema.** Leer duraciones de revisiones en minutos. Cada duración debe ser positiva; 0 indica el final. Los valores negativos se rechazan y no se incluyen. Mostrar cantidad, total, media, máximo, mínimo y número de revisiones de más de 30 minutos. Si se termina sin registrar ninguna, mostrar un mensaje en lugar de calcular estadísticas.

Guarda el programa como `TiemposRevision.java`.

```java
import java.util.Scanner;

public class TiemposRevision {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);
        int cantidad = 0;
        int largas = 0;
        double total = 0;
        double minimo = 0;
        double maximo = 0;

        System.out.print("Minutos de revisión (0 para terminar): ");
        double minutos = teclado.nextDouble();

        while (minutos != 0) {
            if (minutos < 0) {
                System.out.println("La duración debe ser positiva");
            } else {
                if (cantidad == 0) {
                    minimo = minutos;
                    maximo = minutos;
                } else {
                    if (minutos < minimo) {
                        minimo = minutos;
                    }
                    if (minutos > maximo) {
                        maximo = minutos;
                    }
                }

                cantidad++;
                total += minutos;
                if (minutos > 30) {
                    largas++;
                }
            }

            System.out.print("Minutos de revisión (0 para terminar): ");
            minutos = teclado.nextDouble();
        }

        if (cantidad == 0) {
            System.out.println("No se han registrado revisiones");
        } else {
            double media = total / cantidad;
            System.out.println("Revisiones: " + cantidad);
            System.out.println("Total: " + total + " minutos");
            System.out.println("Media: " + media + " minutos");
            System.out.println("Mínimo: " + minimo + " minutos");
            System.out.println("Máximo: " + maximo + " minutos");
            System.out.println("De más de 30 minutos: " + largas);
        }

        teclado.close();
    }
}
```

### 🟩 Explicación del proceso

El 0 es un centinela: termina la entrada y nunca se suma ni se cuenta. Los negativos muestran un aviso. La siguiente lectura se realiza tanto después de un dato válido como después de uno incorrecto, de modo que el bucle puede avanzar en ambos casos.

`cantidad == 0` identifica el primer dato válido **antes** de incrementar el contador. Aunque `minimo` y `maximo` se declaran con 0, ese valor inicial se sustituye por la primera duración válida antes de utilizarlos como extremos. Los ceros iniciales no se comparan como si fueran revisiones.

### 🟦 Traza con 20, -5, 40, 15 y 0

| Entrada | Cantidad | Total | Mínimo | Máximo | Largas |
| --- | --- | --- | --- | --- | --- |
| 20 | 1 | 20 | 20 | 20 | 0 |
| -5 | 1 | 20 | 20 | 20 | 0 |
| 40 | 2 | 60 | 20 | 40 | 1 |
| 15 | 3 | 75 | 15 | 40 | 1 |
| 0 | 3 | 75 | 15 | 40 | 1 |

La media es 25 minutos. El -5 no altera los resultados y el 0 termina. Si la primera entrada es 0, se muestra que no hay revisiones; no se divide entre cero ni se presentan extremos inexistentes.

Para introducir duraciones con decimales, utiliza el separador decimal que reconozca la configuración de `Scanner` de tu equipo, tal como se trabajó en la UT4. Por ejemplo, una configuración regional española suele utilizar la coma. Los datos de la traza son enteros y pueden leerse igualmente con `nextDouble()`.

## 5️⃣ Comprobar qué datos participan

:::tip[Una pregunta para cada resultado]

Antes de calcular, concreta qué se cuenta y qué se suma. Después comprueba una serie vacía, un único dato, varios datos iguales y una serie donde el mayor o el menor aparezcan al final. Un dato rechazado y un centinela no deben modificar los resultados.

:::
