# 6.8. Resumen y referencia rápida

## 1️⃣ Qué aporta cada estructura

Un bucle permite repetir un bloque. Cada ejecución del cuerpo es una iteración. La condición decide si continuar; el estado inicial y las actualizaciones determinan cómo evoluciona la repetición.

| Aspecto | while | do-while | for |
| --- | --- | --- | --- |
| Comprobación | Antes del cuerpo | Después del cuerpo | Antes del cuerpo |
| Ejecuciones mínimas | 0 | 1 | 0 |
| Inicialización habitual | Antes del bucle | Antes o mediante la primera ejecución | Primera parte de la cabecera |
| Actualización habitual | Dentro del cuerpo | Dentro del cuerpo | Tercera parte de la cabecera |
| Situación frecuente | Datos hasta un centinela | Menú o petición de un dato | Recorrido con inicio, límite y avance |

La elección depende del problema. Un recorrido conocido suele expresarse con claridad mediante `for`; una petición obligatoria, mediante `do-while`; una repetición condicionada antes de procesar, mediante `while`.

## 2️⃣ Referencia de sintaxis

Los siguientes esquemas son referencias de estructura, no programas Java completos:

```text
while (condición) {
    cuerpo
}

do {
    cuerpo
} while (condición);

for (inicialización; condición; actualización) {
    cuerpo
}
```

| Elemento | Recordatorio |
| --- | --- |
| `i++` | Incrementa i en una unidad |
| `i--` | Reduce i en una unidad |
| `total += dato` | Añade dato al valor que ya tenía total |
| `if` dentro de un bucle | Selecciona qué hacer en una vuelta |
| `break` | Termina el bucle o switch más cercano que lo contiene |
| `continue` | Omite lo que queda del cuerpo en la vuelta actual |
| Centinela | Dato reservado para terminar, excluido del procesamiento |

Después de `continue`, un `for` realiza su actualización antes de evaluar la condición. Un `while` vuelve directamente a su condición y un `do-while` comprueba su condición final.

## 3️⃣ Contadores, acumuladores y extremos

| Resultado | Cómo se construye | Precaución |
| --- | --- | --- |
| Cantidad | Contador iniciado a 0 | Contar solo los casos correspondientes |
| Suma | Acumulador iniciado a 0 | No reiniciarlo dentro de cada vuelta |
| Media | Suma dividida entre cantidad | Cantidad mayor que 0 y división decimal |
| Máximo | Comparar cada dato con el mayor conocido | Inicializar con el primer dato válido |
| Mínimo | Comparar cada dato con el menor conocido | No suponer que empieza en 0 |

Si no se registra ningún dato válido, no hay media ni extremos que mostrar. Un valor rechazado y un centinela no deben incorporarse a los resultados.

## 4️⃣ Errores frecuentes

| Error | Consecuencia | Qué revisar |
| --- | --- | --- |
| Olvidar una actualización o nueva lectura | Repetición indefinida | Todos los caminos del cuerpo |
| Avanzar en dirección incorrecta | Alejarse del final | Inicio, límite y cambio |
| Confundir `<` con `<=` | Una vuelta de menos o de más | Si el extremo debe incluirse |
| Añadir `;` tras la cabecera de while o for | Cuerpo vacío | Posición de llaves y punto y coma |
| Omitir `;` al final de do-while | Error de compilación | Final de la estructura |
| Incrementar en la cabecera y en el cuerpo | Saltarse valores | Lugar de la actualización |
| Usar continue antes de leer el siguiente dato | No cambiar la condición | Camino que sigue esa instrucción |
| Reiniciar un total en cada vuelta | Perder resultados anteriores | Inicialización antes del bucle |
| Dividir dos enteros para una media | Perder decimales | Tipo de los operandos |
| Calcular una media sin datos | División entre cero | Cantidad de datos válidos |
| Inicializar un mínimo positivo con 0 | Mostrar un valor que no se leyó | Primer dato válido |
| Confundir break de switch con salida del bucle | El menú sigue activo | Estructura que contiene el salto |
| Aceptar una palabra en una lectura numérica | Error de Scanner | Diferencia entre rango y tipo de entrada |

:::tip[Una traza permite ver el problema]

Anota el estado inicial, cada comprobación, la acción y la actualización. Incluye también la última condición falsa. En bucles anidados, distingue la variable exterior de la interior y recuerda que el interior comienza de nuevo en cada vuelta exterior.

:::

## 5️⃣ Qué comprobar antes de darlo por terminado

- El bucle hace exactamente las repeticiones esperadas.
- Se comporta bien con cero vueltas cuando esa estructura lo permite, una vuelta y varias.
- Los límites incluidos y excluidos coinciden con el enunciado.
- Los datos incorrectos reciben el tratamiento solicitado.
- Una nueva lectura o actualización permite avanzar en todos los casos.
- El final inmediato y la ausencia de datos no producen estadísticas inexistentes.
- Los contadores y las sumas corresponden al mismo conjunto de datos cuando se calcula una media.
