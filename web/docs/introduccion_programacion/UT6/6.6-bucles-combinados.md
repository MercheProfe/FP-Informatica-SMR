# 6.6. Bucles combinados

## 1️⃣ Repetir y decidir

Al revisar varios equipos, no todos reciben el mismo tratamiento: unos pueden tener un dato incorrecto, otros necesitar un aviso y otros permitir terminar la ronda. Un bucle controla **cuándo repetir**; un `if` decide **qué hacer en cada vuelta**.

Ya lo hemos utilizado al contar revisiones largas: la lectura se repite, pero el contador aumenta únicamente cuando se cumple su condición. Un `switch` dentro de un bucle permite repetir un menú con varias acciones.

## 2️⃣ break y continue

### 🟧 break: terminar el bucle

Un `break` dentro de un bucle termina inmediatamente el bucle más cercano que lo contiene. La ejecución sigue después de ese bucle, sin esperar a una nueva comprobación de la condición.

En un `switch`, `break` termina el `switch`. Por tanto, si un `switch` está dentro de un bucle, el `break` de un caso no termina automáticamente la repetición.

### 🟦 continue: pasar a la siguiente vuelta

Un `continue` omite las instrucciones que quedan en el cuerpo de la iteración actual. No termina el bucle.

| Estructura | Qué sucede después de continue |
| --- | --- |
| while | Se vuelve a comprobar la condición |
| do-while | Se comprueba la condición final |
| for | Se ejecuta la actualización y después se comprueba la condición |

:::warning[La actualización debe seguir siendo posible]

En un `while`, un `continue` colocado antes de la lectura o actualización puede saltársela. Si el estado no cambia, el programa puede quedarse repitiendo la misma vuelta. Comprueba todos los caminos que puede seguir el cuerpo.

:::

La condición debe explicar el control habitual del bucle. `break` y `continue` pueden expresar una salida anticipada o un caso que se omite, pero no son obligatorios si una condición o un `if` ya permiten comprender bien la solución.

## 3️⃣ Actividad guiada resuelta: ronda de temperaturas

**Problema.** Revisar como máximo cuatro equipos, numerados del 1 al 4. Para cada uno se pide una temperatura entera simulada. El valor -1 termina toda la ronda. Cualquier otro valor negativo se rechaza y se pasa al siguiente equipo, sin repetir su lectura. Para temperaturas de 80 grados o más se muestra «Revisar ventilación»; para las demás no negativas, «Temperatura aceptada». Se informa de cuántas lecturas se han aceptado.

Guarda el programa como `RondaTemperaturas.java`.

```java
import java.util.Scanner;

public class RondaTemperaturas {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);
        int aceptadas = 0;

        for (int equipo = 1; equipo <= 4; equipo++) {
            System.out.print("Temperatura del equipo " + equipo + " (-1 para salir): ");
            int temperatura = teclado.nextInt();

            if (temperatura == -1) {
                System.out.println("Ronda interrumpida");
                break;
            }
            if (temperatura < 0) {
                System.out.println("Lectura rechazada; se pasa al siguiente equipo");
                continue;
            }

            aceptadas++;
            if (temperatura >= 80) {
                System.out.println("Revisar ventilación");
            } else {
                System.out.println("Temperatura aceptada");
            }
        }

        System.out.println("Lecturas aceptadas: " + aceptadas);
        teclado.close();
    }
}
```

### 🟩 Explicación y comprobación

Primero se comprueba el centinela -1. Así no se confunde con los otros valores negativos. `break` salta directamente al mensaje de resumen. El segundo `if` rechaza otros negativos: `continue` evita contarlos y clasificarlos, pero el `for` sí incrementa `equipo`.

Con las entradas 55, -3, 85 y -1:

| Equipo | Entrada | Acción | Aceptadas |
| --- | --- | --- | --- |
| 1 | 55 | Temperatura aceptada | 1 |
| 2 | -3 | Rechazar y avanzar | 1 |
| 3 | 85 | Revisar ventilación | 2 |
| 4 | -1 | Terminar la ronda | 2 |

El umbral de 80 es una regla del problema para practicar decisiones; no es una especificación de seguridad de un componente real. Si la primera entrada es -1, se termina con cero lecturas aceptadas. Si se introducen cuatro temperaturas no negativas, la condición del `for` termina la ronda.

## 4️⃣ Bucles anidados sencillos

Un bucle **anidado** está dentro del cuerpo de otro. Para cada vuelta del exterior se ejecuta el interior completo, salvo que alguna instrucción altere el recorrido.

Piensa en dos rondas de avisos, cada una con tres puestos. El bucle exterior recorre las rondas; el interior, los puestos. Este fragmento ilustrativo se coloca dentro del `main` de un programa:

```java
for (int ronda = 1; ronda <= 2; ronda++) {
    for (int puesto = 1; puesto <= 3; puesto++) {
        System.out.println("Ronda " + ronda + ", puesto " + puesto);
    }
}
```

Se muestran, en orden: ronda 1 puesto 1, ronda 1 puesto 2, ronda 1 puesto 3, ronda 2 puesto 1, ronda 2 puesto 2 y ronda 2 puesto 3. Hay **2 × 3 = 6** ejecuciones de la salida.

Al comenzar cada vuelta exterior, el `for` interior vuelve a inicializar `puesto` en 1. Los nombres distintos ayudan a no confundir los recorridos. Aquí solo se repiten avisos: no se almacenan tablas ni se utilizan matrices.

Un `break` en el bucle interior termina solo ese bucle. El exterior puede continuar. Lo mismo ocurre con `continue`: afecta al bucle más cercano que lo contiene.

## 5️⃣ Elegir la estructura

| Necesidad | Estructura que suele resultar clara | Motivo |
| --- | --- | --- |
| Procesar mientras una entrada no indique el final | while | Comprueba antes de procesar |
| Pedir un dato o mostrar un menú al menos una vez | do-while | La acción precede a la comprobación |
| Recorrer una numeración o repetir una cantidad conocida | for | Reúne inicio, límite y avance |
| Tomar una decisión en cada vuelta | if o switch dentro del bucle | Separa los casos de cada repetición |
| Repetir una pequeña serie por cada ronda | Dos bucles anidados | Representa las dos repeticiones |

No hay una única estructura válida para todos los problemas. Comprueba que la elegida haga visibles el final, la actualización y los casos especiales sin complicar la lectura.
