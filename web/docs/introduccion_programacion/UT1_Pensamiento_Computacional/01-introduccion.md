# UT 1 · Pensamiento computacional

## 1️⃣ ¿Qué aprenderemos?

En esta unidad aprenderemos a **analizar problemas sencillos y
convertirlos en soluciones ordenadas** antes de comenzar a escribir
programas en Java.

Al finalizar la unidad deberías ser capaz de:

-   explicar qué es un programa;
-   distinguir entre **problema, algoritmo y programa**;
-   identificar los **datos de entrada** y los **resultados de salida**;
-   reconocer el **procesamiento** necesario para resolver un problema;
-   dividir un problema grande en problemas más pequeños;
-   escribir algoritmos sencillos;
-   representar soluciones mediante **pseudocódigo**;
-   seguir manualmente la ejecución de un algoritmo;
-   detectar errores sencillos en un algoritmo.

:::info[Idea principal]
Programar no consiste únicamente en aprender la sintaxis de un
lenguaje. Antes de escribir código debemos **entender el problema y
diseñar una solución**.
:::

## 2️⃣ TechFix · El hilo conductor del curso

Durante todo el curso construiremos progresivamente un pequeño sistema
de gestión para un servicio técnico informático.

Cada unidad añadirá nuevas capacidades.

  Unidad     Evolución de TechFix
  ---------- ---------------------------------------
  **UD1**    Diseñamos cómo resolver los problemas
  **UD2**    Creamos nuestros primeros programas
  **UD3**    Permitimos introducir datos
  **UD4**    El programa toma decisiones
  **UD5**    Creamos menús y repetimos operaciones
  **UD6**    Organizamos el programa en métodos
  **UD7**    Gestionamos conjuntos de equipos
  **UD8**    Creamos un inventario dinámico
  **UD9**    Guardamos los datos en ficheros
  **UD10**   Construimos la aplicación completa

:::note[TechFix]
No intentaremos construir toda la aplicación desde el principio. La
iremos desarrollando paso a paso a medida que aprendamos nuevos
conceptos de programación.
:::
