## 3️⃣ ¿Qué significa programar?

Para comprender qué hacemos cuando programamos debemos diferenciar tres
conceptos.

### 🟩 Problema

Un **problema** es una situación para la que queremos obtener una
solución.

> **Ejemplo:** calcular cuánto debe pagar un cliente por una reparación.
>
### 🟧 Algoritmo

Un **algoritmo** es una secuencia ordenada y finita de pasos que permite
resolver un problema.

Por ejemplo:

1.  Conocer el precio de las piezas.
2.  Conocer las horas de trabajo.
3.  Calcular el coste de la mano de obra.
4.  Sumar piezas y mano de obra.
5.  Mostrar el precio final.

### 🟥 Programa

Un **programa** es la implementación de uno o varios algoritmos
utilizando un lenguaje de programación.

Durante este curso utilizaremos **Java**.

:::tip[Recuerda]
**PROBLEMA → ALGORITMO → PROGRAMA**
:::
