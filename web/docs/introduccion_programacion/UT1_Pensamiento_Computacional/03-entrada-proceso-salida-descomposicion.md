## 4️⃣ Entrada → Proceso → Salida

Muchos problemas informáticos pueden analizarse utilizando tres
elementos:

:::info[Esquema fundamental]
**ENTRADA → PROCESO → SALIDA**
:::
### 🟩 1. Entrada

Es la **información que recibe el programa**.

Ejemplos:

-   nombre del cliente;
-   precio;
-   número de horas;
-   cantidad de equipos;
-   temperatura;
-   dirección IP.

### 🟧 2. Proceso

Son las **operaciones que se realizan utilizando los datos**.

Ejemplos:

-   sumar;
-   multiplicar;
-   calcular una media;
-   comparar valores;
-   buscar información.

### 🟥 3. Salida

Es el **resultado que produce el programa**.

Ejemplos:

-   precio final;
-   mensaje;
-   informe;
-   diagnóstico;
-   número de equipos.

### 🟪 Ejemplo completo

Un cliente compra:

-   teclado: **25 €**
-   ratón: **15 €**

  | Elemento | Valor |
|---|---|
| **Entrada** | 25 y 15 |
| **Proceso** | 25 + 15 |
| **Salida** | 40 € |

### 🟦 Actividad 2.1 · Identifica EPS

Para cada problema identifica **Entrada, Proceso y Salida**.

**Problema A:** calcular la capacidad total de tres discos duros.

**Problema B:** calcular el precio de cinco cables de red.

**Problema C:** calcular cuánto ocupa una copia de seguridad de varias
carpetas.

**Problema D:** calcular el precio de una reparación con piezas y mano
de obra.

### 🟧 Actividad 2.3 · Diseña el problema

Cada pareja o grupo inventará un problema relacionado con SMR.

Puede estar relacionado con:

-   almacenamiento;
-   redes;
-   reparación;
-   usuarios;
-   copias de seguridad;
-   impresoras;
-   consumibles.

Después intercambiará el problema con otra pareja.

La otra pareja deberá descubrir:

**Entrada → Proceso → Salida**

## 5️⃣ Descomponer problemas

Una de las capacidades fundamentales del pensamiento computacional es
aprender a **dividir un problema**.

:::tip[Principio fundamental]
Si un problema parece demasiado complicado, **divídelo en problemas
más pequeños**.
:::
### 🟩 Ejemplo · TechFix

Queremos resolver este problema:

**Gestionar un servicio técnico informático.**

Es demasiado grande para abordarlo directamente. Podemos dividirlo.

#### Gestión de clientes

-   Registrar cliente.
-   Modificar cliente.
-   Consultar cliente.

#### Gestión de equipos

-   Registrar equipo.
-   Consultar equipo.
-   Eliminar equipo.

#### Gestión de reparaciones

-   Crear incidencia.
-   Asignar técnico.
-   Calcular presupuesto.
-   Cerrar reparación.

#### Gestión económica

-   Calcular precio.
-   Aplicar impuestos.
-   Generar factura.

Acabamos de realizar una **descomposición**.

Esta técnica será fundamental cuando programemos aplicaciones.

### 🟧 Actividad 3.1 · Descomponer una instalación

**Problema:** preparar diez ordenadores nuevos para un aula.

Divide el problema en tareas más pequeñas.

### 🟥 Actividad 3.2 · El árbol de problemas

En grupos, crea un esquema para:

**Montar un aula informática desde cero.**

Un primer nivel podría ser:

-   hardware;
-   red;
-   software;
-   usuarios;
-   seguridad.

Ahora vuelve a dividir cada rama.
