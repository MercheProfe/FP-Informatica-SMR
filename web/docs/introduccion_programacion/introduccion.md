Esta asignatura optativa de **2.º de Sistemas Microinformáticos y Redes (SMR)** está pensada para aprender a programar **desde cero**. No es necesario haber programado antes.

A lo largo del curso aprenderemos a analizar problemas, diseñar soluciones y convertirlas en programas utilizando **Java** como lenguaje de programación y **Visual Studio Code (VS Code)** como entorno de trabajo.

:::info[Idea fundamental]
Programar no consiste solamente en escribir código. Antes de programar debemos **comprender el problema, identificar los datos, pensar una solución y organizar los pasos necesarios para resolverlo**.
:::

## 1️⃣ ¿Qué aprenderemos?

El objetivo principal de la asignatura es adquirir una **base sólida de programación** que nos permita comprender cómo funciona un programa y crear nuestras propias soluciones.

Aprenderemos a:

- Analizar un problema antes de comenzar a programar.
- Diseñar algoritmos y expresarlos mediante pseudocódigo.
- Comprender las partes fundamentales de un programa.
- Preparar un entorno de desarrollo para trabajar con Java.
- Utilizar variables, tipos de datos y operadores.
- Crear programas que soliciten información al usuario.
- Hacer que un programa tome decisiones.
- Repetir automáticamente determinadas tareas.
- Dividir un problema complejo en problemas más pequeños mediante métodos.
- Trabajar con conjuntos de datos.
- Guardar y recuperar información utilizando ficheros.
- Introducirnos en el uso de clases y objetos.
- Diseñar, programar y probar una pequeña aplicación completa.

:::tip[No necesitas experiencia previa]
Empezaremos desde los conceptos más básicos. Los contenidos se introducirán de forma progresiva y siempre acompañados de ejemplos y actividades prácticas.
:::

## 4️⃣ De un problema a un programa

Durante el curso seguiremos habitualmente un proceso similar:

```text
PROBLEMA
   │
   ▼
ANÁLISIS
   │
   ▼
ENTRADAS - PROCESO - SALIDAS
   │
   ▼
ALGORITMO
   │
   ▼
CÓDIGO JAVA
   │
   ▼
EJECUCIÓN
   │
   ▼
PRUEBAS
   │
   ▼
CORRECCIÓN Y MEJORA
```

### 🟩 Analizar antes de programar

Al principio dedicaremos más tiempo al análisis y al diseño de la solución. Conforme avancemos, este proceso se irá haciendo cada vez más natural.

### 🟧 Del algoritmo al código

Una vez definida la solución, la expresaremos mediante un algoritmo y posteriormente la transformaremos en instrucciones que Java pueda ejecutar.

### 🟦 Probar y mejorar

Un programa no está terminado cuando compila. Debemos ejecutarlo con distintos datos, comprobar los resultados y corregir los problemas detectados.

:::warning[Antes de programar]
No empieces a escribir instrucciones inmediatamente. Primero asegúrate de que **entiendes qué problema tienes que resolver y qué resultado debe producir el programa**.
:::

## 5️⃣ ¿Cómo vamos a trabajar?

La asignatura tendrá un enfoque principalmente **práctico**.

### 🟩 Explicaciones y ejemplos

Cada concepto nuevo se presentará mediante explicaciones breves y ejemplos que podremos analizar y ejecutar paso a paso.

### 🟧 Ejercicios y retos

Realizaremos ejercicios para practicar cada concepto y pequeños retos en los que tendremos que diseñar nuestra propia solución.

### 🟦 Prácticas relacionadas con SMR

Siempre que sea posible utilizaremos situaciones relacionadas con nuestro ámbito profesional:

- Equipos informáticos.
- Memoria y almacenamiento.
- Temperaturas y estado de los equipos.
- Servicios técnicos.
- Inventarios.
- Incidencias.
- Usuarios.
- Ficheros y directorios.

## 6️⃣ Aprender a programar también significa equivocarse

Cuando programamos aparecen errores. Detectarlos, comprenderlos y corregirlos forma parte del proceso de aprendizaje.

### 🟥 Errores de compilación

Java no puede compilar nuestro código porque existe algún problema en las instrucciones.

### 🟧 Errores de ejecución

El programa comienza a ejecutarse, pero se produce un problema durante su funcionamiento.

### 🟪 Errores lógicos

El programa se ejecuta sin mostrar errores, pero el resultado obtenido no es correcto.

:::danger[Cuando aparezca un error]
Lee el mensaje que proporciona el entorno, localiza dónde se produce el problema y modifica **una cosa cada vez**. Aprender a depurar un programa es tan importante como aprender a escribirlo.
:::

## 7️⃣ ¿Dónde queremos llegar?

Al finalizar la asignatura deberíamos ser capaces de enfrentarnos a un problema sencillo siguiendo un proceso ordenado:

```text
ENTENDER
   ↓
DISEÑAR
   ↓
PROGRAMAR
   ↓
PROBAR
   ↓
CORREGIR
   ↓
MEJORAR
```

### 🟩 El objetivo

El objetivo no es memorizar todas las instrucciones de Java, sino aprender a **pensar y trabajar como programadores**.

### 🟦 Proyecto final

Terminaremos el curso desarrollando una pequeña aplicación que integrará los principales contenidos aprendidos: entrada de datos, decisiones, bucles, métodos, colecciones y persistencia de información.
