# Aplicaciones Web

En este módulo aprenderemos **cómo funciona la Web, cómo se construyen páginas web y cómo se utilizan y administran aplicaciones web en entornos reales**.

Comenzaremos entendiendo qué ocurre cuando escribimos una dirección en el navegador y accedemos a una página. Después construiremos nuestras propias páginas utilizando **HTML y CSS**, añadiremos una primera capa de interactividad con **JavaScript** y, finalmente, trabajaremos con aplicaciones web utilizadas para gestionar contenidos, usuarios, archivos, formación y trabajo colaborativo.

:::info[Objetivo del módulo]
El objetivo no es únicamente aprender a crear páginas web. También aprenderemos a **instalar, configurar, utilizar y administrar diferentes tipos de aplicaciones y servicios web**, relacionándolos con situaciones habituales en una empresa.
:::

## 1️⃣ ¿Qué aprenderemos?

A lo largo del curso aprenderemos a:

- Comprender cómo funcionan **Internet y la Web**.
- Diferenciar los elementos de una arquitectura **cliente-servidor**.
- Entender qué ocurre durante una petición y una respuesta web.
- Crear páginas web estructuradas mediante **HTML**.
- Diseñar y personalizar páginas utilizando **CSS**.
- Crear diseños sencillos adaptados a distintos tamaños de pantalla.
- Añadir interactividad básica mediante **JavaScript**.
- Comprender la diferencia entre una página creada manualmente y una web gestionada mediante un **CMS**.
- Instalar y configurar gestores de contenidos.
- Gestionar **usuarios, roles, permisos y contenidos**.
- Conocer y utilizar plataformas de aprendizaje en línea.
- Gestionar archivos y documentos mediante aplicaciones web.
- Utilizar herramientas de **ofimática y trabajo colaborativo en la Web**.
- Conocer aplicaciones web utilizadas habitualmente en entornos profesionales.
- Aplicar parte de estos conocimientos durante la **formación en empresa**.

:::tip[Forma de trabajo]
La asignatura tendrá un carácter principalmente **práctico**. Las explicaciones teóricas servirán como base para realizar actividades, pequeñas prácticas y proyectos que iremos ampliando a medida que aprendamos nuevas tecnologías.
:::

## 2️⃣ Organización del módulo

El módulo se organizará en las siguientes **unidades de trabajo (UT)**. El recorrido comenzará comprendiendo cómo funciona la Web y avanzará progresivamente hacia la creación, configuración y administración de aplicaciones web.

<div className="ut-grid">

<div className="ut-card">

### 🟩 UT1. Internet y arquitectura cliente-servidor

Comprenderemos cómo funciona la Web: Internet, navegador, servidor web, URL, dominio, HTTP/HTTPS y modelo cliente-servidor.

**Resultado:** entender qué sucede desde que escribimos una dirección en el navegador hasta que recibimos y visualizamos una página web.

</div>

<div className="ut-card">

### 🟧 UT2. HTML: estructura y contenido de una web

Construiremos páginas con **HTML**, trabajando estructura, textos, enlaces, imágenes, listas, tablas, formularios, multimedia, etiquetas semánticas y rutas relativas.

**Resultado:** crear una web sencilla formada por varias páginas relacionadas entre sí.

</div>

<div className="ut-card">

### 🟥 UT3. CSS: diseño y presentación

Utilizaremos **CSS** para controlar el aspecto visual de las páginas: selectores, colores, tipografías, modelo de caja, distribución, Flexbox y diseño *responsive* básico.

**Resultado:** mejorar progresivamente el diseño de las páginas creadas con HTML.

</div>

<div className="ut-card">

### 🟪 UT4. JavaScript básico

Añadiremos pequeñas interacciones mediante **JavaScript**: variables, operadores, condiciones, funciones, eventos, introducción al DOM, modificación de contenido y validaciones sencillas.

**Resultado:** comprender cómo añadir comportamiento a una página web.

</div>

<div className="ut-card">

### 🟦 UT5. Gestores de contenidos (CMS)

Aprenderemos otra forma de crear y mantener sitios web mediante **CMS**: instalación, configuración, contenidos, usuarios, roles, menús, temas, extensiones, seguridad, actualizaciones y copias de seguridad.

**Resultado:** comparar una web creada directamente con HTML/CSS/JavaScript con una administrada mediante un CMS.

</div>

<div className="ut-card">

### 🟩 UT6. Plataformas web, gestión documental y colaboración

Trabajaremos con aplicaciones destinadas a gestionar **formación, usuarios, documentos y trabajo colaborativo**, incluyendo almacenamiento web, permisos y herramientas de ofimática web.

**Resultado:** aplicar estas herramientas a las necesidades digitales de una pequeña organización.

</div>

<div className="ut-card">

### 🟧 UT7. Aplicaciones web en el entorno profesional

Veremos aplicaciones web habituales en una organización: correo, calendarios, contactos, citas, tareas, almacenamiento compartido, colaboración, usuarios, permisos y seguridad de acceso.

**Resultado:** preparar el uso de estas herramientas en situaciones reales y en la formación en empresa.

</div>

</div>

## 3️⃣ Del navegador a la empresa

El recorrido del módulo seguirá una progresión sencilla:

> **Comprender la Web → Crear una web → Diseñarla → Añadir
> interactividad → Administrar aplicaciones web → Utilizarlas en un
> entorno profesional**

De esta forma, cada unidad utilizará conocimientos adquiridos
anteriormente.

Por ejemplo, primero aprenderemos a construir una página con HTML y CSS.
Más adelante podremos comprender mejor cómo un gestor de contenidos
genera y administra esas páginas automáticamente.

## 5️⃣ Tecnologías y herramientas

Durante el módulo utilizaremos diferentes tecnologías y aplicaciones relacionadas con la Web.

| Tecnología o herramienta | ¿Para qué la utilizaremos? |
|---|---|
| **HTML** | Crear la estructura y el contenido de las páginas web |
| **CSS** | Diseñar y dar estilo a las páginas |
| **JavaScript** | Añadir interactividad básica |
| **HTTP/HTTPS** | Comprender la comunicación entre cliente y servidor |
| **CMS** | Crear y administrar sitios mediante gestores de contenidos |
| **Visual Studio Code** | Escribir y organizar nuestro código HTML, CSS y JavaScript |
| **Aplicaciones web** | Gestionar usuarios, contenidos, archivos y trabajo colaborativo |


:::tip[Nuestro entorno de trabajo]
Utilizaremos principalmente **Visual Studio Code** para crear nuestras páginas HTML, hojas de estilo CSS y programas sencillos en JavaScript.
:::

## 6️⃣ ¿Cómo trabajaremos?

A lo largo del módulo combinaremos:

-   explicaciones breves;
-   ejemplos realizados en clase;
-   actividades guiadas;
-   prácticas individuales;
-   pequeños retos;
-   proyectos progresivos;
-   instalación y configuración de aplicaciones;
-   resolución de problemas similares a los que podemos encontrar en un
    entorno profesional.


:::warning[Importante]
En este módulo no basta con memorizar conceptos. Aprenderemos principalmente **haciendo**: creando páginas, modificando código, configurando aplicaciones, detectando errores y buscando soluciones.
:::

## 7️⃣ Al terminar el módulo...

Deberíamos ser capaces de comprender mucho mejor qué hay detrás de una
aplicación web y desenvolvernos con soltura en tareas básicas de
**creación, configuración, administración y utilización de servicios
web**.

El objetivo es pasar de ser simplemente usuarios de la Web a **entender
cómo funciona y ser capaces de trabajar con ella como profesionales de
informática**.
