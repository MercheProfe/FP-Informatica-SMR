# UT4 · Instalación, configuración y gestión de un CMS

Hasta ahora hemos creado páginas web escribiendo HTML y CSS. En esta unidad aprenderemos otra forma de construir y mantener sitios web: utilizar un **gestor de contenidos** o **CMS**.

Trabajaremos principalmente con **WordPress**. No nos limitaremos a diseñar páginas: también aprenderemos a preparar una instalación, configurar el sitio, administrar usuarios y mantenerlo en funcionamiento.

## 1️⃣ ¿Qué aprenderemos?

Al finalizar la unidad serás capaz de:

- Explicar qué es un CMS y cuándo resulta útil.
- Identificar los requisitos para instalar WordPress.
- Instalar y configurar un sitio de prácticas.
- Gestionar usuarios y permisos.
- Organizar páginas, entradas, imágenes y menús.
- Personalizar la apariencia mediante temas y ajustes sencillos de CSS.
- Instalar y configurar plugins, incluido un foro con reglas de acceso.
- Comprobar el funcionamiento del sitio, actualizarlo y aplicar medidas de seguridad.
- Realizar copias de seguridad y comprobar cómo recuperar los contenidos.

## 3️⃣ ¿Cómo vamos a trabajar?

Crearemos un **sitio web de prácticas** que irá creciendo durante la unidad. Primero conoceremos WordPress y después realizaremos tareas de instalación, configuración y administración.

Alternaremos explicaciones breves, demostraciones, trabajo individual y comprobaciones del resultado. Antes de modificar configuraciones importantes, aprenderemos a guardar una copia de seguridad.

:::tip[Relaciona lo nuevo con lo que ya sabes]
HTML define la estructura de una página y CSS su presentación. WordPress nos permite gestionar gran parte del contenido desde un panel de administración, aunque HTML y CSS siguen formando parte de la web que se muestra en el navegador.
:::

## 4️⃣ ¿Qué tendremos que demostrar?

El objetivo no será únicamente presentar una web bonita. También deberás demostrar que sabes **instalarla, configurarla, probarla y mantenerla**.

Entre las evidencias de trabajo estarán una instalación funcional, usuarios con distintos permisos, un sitio personalizado, plugins y menús configurados, un foro con reglas de acceso y una copia de seguridad de los contenidos.

:::info[Resultado de aprendizaje RA1]
**Instala gestores de contenidos, identificando sus aplicaciones y configurándolos según requerimientos.**
:::
